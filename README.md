# EL_Coby | الكوبي

واجهة متجر تجريبية بالعربية والإنجليزية باستخدام HTML وCSS وJavaScript، بدون إطار عمل أو خطوة build.

## حالة المشروع

هذا **عرض frontend وليس متجرًا جاهزًا للإنتاج**:

- المنتجات والصور والأسعار والمقاسات والعروض والتقييمات وسياسات الشحن والضمان والاسترجاع أمثلة غير موثقة تجاريًا.
- الملف الشخصي مجرد اسم عرض محفوظ في `localStorage` داخل هذا المتصفح. لا توجد حسابات حقيقية أو مصادقة أو كلمة مرور.
- السلة والمفضلة واللغة والمظهر محفوظة محليًا. مسح بيانات الموقع يفقدها، ولا تتزامن بين الأجهزة.
- الخصومات والعجلة تعمل في المتصفح، ويمكن تعديلها. ليست نظام خصومات آمنًا أو قابلًا للفرض من جهة الخادم.
- واتساب يفتح مسودة رسالة إلى رقم مطور العرض الموجود في `WA`، ولا يرسلها تلقائيًا ولا يؤكد الطلب. السلة لا تُمسح عند فتح المسودة. لا تدخل بيانات شخصية حقيقية أثناء التجربة.
- لا يوجد backend أو دفع إلكتروني أو مخزون فعلي أو حساب لتكلفة الشحن غير المجاني. الإجمالي المعروض هو إجمالي المنتجات بعد الخصم فقط.

Live demo: https://faresdief.github.io/EL_Coby/

## التشغيل محليًا

استخدم خادم HTTP لأن JavaScript مقسم إلى ES modules. لا تفتح `index.html` مباشرة عبر `file://`.

```sh
python3 -m http.server 8000
```

افتح `http://localhost:8000`. الخطوط من Google Fonts والصور من Unsplash تحتاج إنترنت. الموقع ليس PWA ولا يعد بالعمل دون اتصال.

## الاختبارات

Node.js 20 أو أحدث:

```sh
npm ci
npm test
```

اختبار متصفح منفصل باستخدام Playwright وChrome مثبت محليًا:

```sh
CHROME_PATH=/usr/bin/google-chrome npm run test:browser
```

غيّر `CHROME_PATH` إلى مسار Chrome عندك. الاختبار يشغل خادمًا محليًا مؤقتًا، يمنع الطلبات الخارجية، ويعترض فتح واتساب. لا يرسل رسائل ولا ينشئ طلبات. لقطات الاختبار في `test-results/` لا تدخل في git. الصور الخارجية لا تُختبر في هذا الاختبار المعزول.

الاختبارات تغطي فساد التخزين، القيم السالبة والنصية، ترحيل مفاتيح السلة القديمة، الألوان والمقاسات، حد الكمية، إجمالي المنتجات، حدود الخصومات وصلاحيتها، الشحن المجاني، اللغتين، الملف المحلي، احتفاظ السلة عند فتح مسودة واتساب، وعرض الهاتف.

## الملفات

| الملف | الوظيفة |

| `commerce.test.js` و`browser-smoke.js` | اختبارات الحسابات واختبار متصفح معزول |

## تعديل البيانات

عدّل `P` في `data.js` لإضافة منتج أو سعر أو لون أو مقاس. حافظ على `id` ثابتًا حتى تظل السلال القديمة قابلة للقراءة. المفتاح الحالي للسلة هو `id~colorIndex~sizeIndex`، وتُرحّل مفاتيح الفهرس الرقمية القديمة إلى الصيغة الجديدة. تُرفض المنتجات المحذوفة والكميات غير الصحيحة والمتغيرات غير الموجودة.

`CODES` يحدد نوع الخصم (`pct` أو `flat` أو `ship`)، قيمته والحد الأدنى. `FREE` حد الشحن المجاني بعد الخصم و`OFFER_MIN` مدة عرض العجلة. تكلفة الشحن الأخرى غير محسوبة. لا تستخدم هذه القواعد كمرجع آمن للدفع.

قبل أي استخدام تجاري: تحقّق من كل المعلومات والصور والحقوق، استبدل وجهة واتساب بالوجهة المعتمدة، أضف حسابات ومخزونًا وأسعارًا وخصومات وتحققًا من الطلبات على خادم، وحدد الشحن والخصوصية والسياسات الفعلية. استبدل التقييمات التجريبية بتقييمات موثقة أو احذفها.

## حدود المراجعة

هذه اختبارات frontend محلية وليست تدقيقًا أمنيًا أو إثباتًا لصحة بيانات متجر حقيقي. لا تتضمن إرسال واتساب فعليًا أو اختبار دفع أو مخزون أو حسابات خادم.

راجع `LICENSE` لشروط الكود. الترخيص لا يثبت ملكية أو ترخيص الصور الخارجية.
